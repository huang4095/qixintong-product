# 企信通功能清单

[返回产品介绍](../README.md) · [近期修复与界面调整](#近期修复与界面调整) · [查看页面图集](页面图集.md)

PC 提供管理配置、主要业务办理和财务回查。移动 H5 提供面向员工和业务角色的场景入口。菜单、操作和记录范围按租户套餐、角色及具体业务授权开放。购买前可按本页列出需要演示的场景。

## 经营目标与组织协作

| 模块 | PC 管理端 | 移动 H5 |
| --- | --- | --- |
| 工作台 | 个人待办、计划和申请。经营工作台可查看授权范围内的目标、经营指标和异常事项。 | 工作台汇集常办事项、个人待办、协同任务和拜访任务。 |
| 经营目标 | 公司、部门、个人目标逐级下达。定性目标可提交验收依据，量化目标可配置指标版本、查看实际值。 | 按权限查看业绩目标、业绩达成和本人任务。 |
| 计划与任务 | 维护日周月计划。从个人月周目标生成计划、从计划生成任务。负责人按接收人复核反馈和验收。 | 查看个人计划和任务，提交任务反馈。 |
| OA 与审批 | 日程及工作汇报。办理出差、采购、日常和差旅报销及已启用的人事申请。审批可核对表单、状态和记录。 | 常用 OA 申请、审批进度、待办及任务入口。 |
| 人事与假勤 | 组织人事、员工档案、账号绑定、班次、考勤、节假日和社保。已配置的请假、补卡可关联考勤结果。 | 个人考勤、档案及员工自助查询。 |
| 绩效与薪资 | KPI 模板、月度考核、业务指标冻结、评分及归档。工资试算、确认、关账及工资条。历史绩效变动可按后续工资月补差。 | 查看个人绩效和工资条。 |

**可演示** · 从部门目标派发个人计划和任务，再用员工账号提交反馈、用发布人账号验收。对纳入考核的任务，可回查考核和工资试算使用的依据。

## 客户经营与购销

| 模块 | PC 管理端 | 移动 H5 |
| --- | --- | --- |
| 客商与主数据 | 统一管理客商、物料、单位、编码规则和本方企业主体。历史客户和供应商保留跨模块映射。 | 客商、物料档案查询及授权维护入口。 |
| CRM 跟进 | 线索、客户、联系人、公海、商机、跟进记录。 | 客户和线索查询、跟进、现场拜访。 |
| 客户车辆 | 按客户维护车辆及行驶证信息。在开通并配置第三方 OCR 后，可识别证照并回填待核对字段。 | 从客户详情查看和维护车辆信息。 |
| 合同与回款 | 合同、审批与分期回款计划。按权限核对已收、待收及 CRM、ERP 关联记录。 | 合同、回款相关列表与详情。 |
| 拜访管理 | 按客户或级别配置应访次数及打卡条件，生成个人任务。核对履约率、覆盖率、证据及月结结果。 | 我的拜访任务、到场打卡、远程跟进和完成进度。 |
| ERP 销售 | 选择同客商、同主体的 CRM 合同建订单，办理审批、发货通知和关联原单查询。 | 购销订单列表、详情及授权操作入口。 |
| ERP 采购 | 员工申请审批后转采购订单或直接建单，管理到货通知，回查入库、退货和财务原单。 | 采购申请、订单和授权的收发入口。 |

**可演示** · 销售负责人在合同回查分期收款，财务从应收或凭证查回原出库单。有效回款分配和银行实际到账分别记录。

## 统一仓库与生产

| 模块 | PC 管理端 | 移动 H5 |
| --- | --- | --- |
| 仓库与库存 | 仓库、物料、单位、批次及期初数量。查看在库、锁定、可用数量与库存流水。 | 按仓库和物料查看余额、批次、流水和原单。 |
| 收货与发货 | 采购入库及退货、销售出库及退库、其他入出库、生产领退料、生产入库与外协收发。支持按权限制单、复核和过账。 | 采购入库、销售出库及领退料等已授权场景。 |
| 实物盘点 | 盘点任务、盲盘录入、差异复核、重新取账、复盘及过账。 | 查看任务，录入和提交实盘数量。 |
| 库存调拨 | 按物料和批次选择调出与调入仓。过账后两侧流水关联同一单据。 | 查询调拨及授权办理。 |
| 生产工艺 | 生产计划、工单、自制和代工、BOM、工序、工艺路线与生产排班。 | 查看生产计划、工单及实际产出。 |
| 报工和质检 | 工序报工、收发货或过程质检、工序耗料、合格数量与生产签收。 | 授权的生产报工、质检及入库详情。 |
| 委外加工 | 外协订单、待发料、待回厂入库、材料实耗和余料回收。 | 外协和回厂记录的查询及授权入口。 |

**可演示** · 仓库按批次将原料转入线边仓，工序报工按配置记录耗料，仓库分批签收合格成品。通过工单或仓库单号核对来源、批次和余量。成品签收需满足租户启用及物料、仓库配置条件。

## 财务管理

| 模块 | PC 管理端 | 移动 H5 |
| --- | --- | --- |
| 账套与财务设置 | 按本方企业主体管理人民币账套、会计期间、科目、辅助核算、凭证字和结算账户。 | 财务入口随角色与账套权限开放。 |
| 应收与收款 | 按已审核的出库和退货核对应收，登记到账、分配分期、审核核销，回写 CRM。 | 授权的往来款和收款办理入口。 |
| 应付与付款 | 按采购原单核对应付，发起付款审批、确认银行实付、登记流水与回单、核销相应原单。 | 授权的付款办理及实付记录查询。 |
| 费用与报销 | 日常和差旅报销审批后进入财务结算。确认费用、登记实付、办理冲回、核对银行流水。 | 报销申请及其审批或结算进度查询。 |
| 凭证和账簿 | 按原单回查凭证并审核过账。总账、明细账、科目余额及已配置的财务报表。 | 相关单据详情按权限展示凭证关联信息。 |
| 对账与结账 | 业务与会计对账，核对未过账、跨期或缺凭证明细。按账套和期间办理期末结账。 | 以授权明细查询为主。 |

**可演示** · 从同一笔采购入库核对应付发生额，再打开已实付的付款单和凭证。付款或报销实付由出纳依据银行凭据登记，财务按所选账套和期间对账。

## 近期修复与界面调整

以下改动已合入产品主线。可预约按目标版本与业务角色演示。

### 人事与薪资

- PC **工资条发放向导**修复模板加载和跨步骤选人，按已应用筛选的员工名单发放。
- PC 和 H5 查看**本人工资条明细**前须重新验证登录密码，薪资金额集中在验证后的明细查看。H5 修复工资条的月份筛选和已读状态。
- H5 在未发布自定义菜单时也能找到**考勤申请**入口，刷新申请页后可正确返回工作台。员工档案按基本、通讯、岗位等信息分组，社保明细可按年度查看。绩效按实际办理阶段展示页签和待办数量，可回查任务证据和归档结果。

### 财务

- H5 切换**财务账套**后，凭证、账簿和设置页按当前账套加载，旧请求的结果会被丢弃。账套初始化校验科目编码层级，成员授权保存时核对当前权限和并发修改。
- H5 补齐**凭证过账、反过账**与确认交互。凭证移号前预览原凭证，反结账时复核所选期间。账簿按账套和科目组合筛选，下钻保留筛选条件，历史账簿仍可按停用的辅助项查询。
- **分期收款**按计划与合同余额校验，H5 付款和退款按原单余额校验金额及方向。PC 报销结算完善回单上传和查看，对账时核对银行流水、付款登记及已过账凭证金额。

### H5 导航与页面重排

- H5 底栏分为**工作台、功能、消息、通讯录、我的**。工作台汇总待办、协同任务和拜访任务，个人中心集中档案、工资条、社保与绩效入口。租户管理员可在 PC 配置分组、图标和角色可见性，预览后发布，H5 菜单和搜索读取同一份布局。
- **购销、仓库和生产**统一列表卡片、详情及录入表单的布局，合并生产基础资料和检验档案的分散入口。盘点和批次调拨按移动端办理步骤调整表单。**移动财务**重排单据、账套设置和账簿筛选，金额分区显示，折叠筛选方便在窄屏查单。

## 交付前怎样核对

1. 确认需要的模块、PC 或 H5 入口及参与角色。
2. 选一条实际业务流程，按发起、审批或过账、结果回查三个环节演示。
3. 核对正常单据及需要验证的例外，例如退货、重复提交、账套越权或数据回退。
4. 在订单附件写明交付版本、初始化方式、业务范围和验收步骤。原生 App 适配、第三方账号及服务费用按确认的交付范围执行。
