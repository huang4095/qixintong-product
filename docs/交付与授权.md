# 企信通商业源码交付与授权

**统一售价人民币 ¥4,980，一次付费。** 每份授权对应一个实名个人或企业主体。可用于学习、二次开发和本主体自用部署，也可登记一个终端客户项目并交付部署成品。终端客户如需接收含企信通自有部分的源码，可按同一价格独立取得授权。具体版本、授权主体、项目和交付约定以订单及商业协议为准。

## 交付清单

| 交付项 | 内容 |
| --- | --- |
| 版本清单 | 同一约定版本的服务端、PC 管理端和 H5 源码与依赖锁定说明 |
| 安装资料 | 适用运行环境、数据库初始化材料与顺序、配置示例、构建和部署步骤 |
| 联调资料 | 合成业务样例、演示角色、代表性流程和验收路径 |
| 授权资料 | 授权主体、许可版本和用途、交付范围、第三方许可声明 |

预订演示时可先确认要用的模块、PC 与 H5 功能差异、开发环境和交付项目。上线前按实际角色核对关键操作和数据权限。自行实施所需的服务器、域名及第三方账号由使用方准备。原生 App 及涉及平台签名或独立云服务的功能，按具体项目确认适配与交付范围。

## 权限与第三方许可

购买者可以将源码置于受控的内部私有仓，用于本授权下的开发、部署和学习。企信通自有源码及交付材料按商业协议授权。对外公开、转售、转授权和交付含企信通自有部分的二开源码，按商业协议约定。沿用的芋道、Vben、unibest 等上游代码和其他依赖，各自适用原许可证，相关版权和许可声明随发行版本提供。
